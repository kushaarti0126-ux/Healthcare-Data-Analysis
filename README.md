# Healthcare No-Show Analysis

## 📌 Project Overview
This project analyzes healthcare appointment data to understand the reasons behind patient no-shows.

## 🛠 Tools Used
- Excel
- Power BI
- Python (Pandas, Matplotlib)

## 📊 Key Insights
- Most no-shows are from age group 20-40
- SMS reminders reduced no-show rate
- Certain neighborhoods show higher no-show patterns

## 📂 Dataset
- healthcare_noshows_appt.csv
